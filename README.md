# Hiral Shah - Personal Portfolio

A premium, modern, and fully responsive personal portfolio website showcasing my skills, projects, education, certifications, and a functional contact form.

🔗 **Live Demo:** [https://hiral-portfolio.onrender.com](https://hiral-portfolio.onrender.com)

## ✨ Features
- **Premium Aesthetics:** Glassmorphism design, subtle gradients, and custom scrollbar/selection styling.
- **Dark/Light Mode:** Seamlessly toggle between dark and light themes (defaults to Dark Mode).
- **Smooth Animations:** Intersection Observer API for scroll-reveal animations and a custom animated cursor.
- **Fully Responsive:** Optimized layout for Desktop, Tablet, and Mobile devices.
- **Working Contact Form:** Asynchronous POST requests powered by an Express.js backend.
- **Zero Frameworks on Frontend:** Pure Vanilla HTML, CSS, and JavaScript for maximum performance.

## 🛠️ Tech Stack
**Frontend:**
- HTML5
- CSS3 (Vanilla, custom CSS variables)
- JavaScript (ES6+, DOM Manipulation, Fetch API)
- Feather Icons (via CDN)

**Backend:**
- Node.js
- Express.js (Handling static files and `/api/contact` POST route)

## 🚀 Getting Started

If you want to run this project locally on your machine, follow these steps:

### 1. Prerequisites
- [Node.js](https://nodejs.org/) installed on your machine.
- Git installed.

### 2. Installation

Clone the repository:
```bash
git clone https://github.com/hiral1609/portfolio.git
cd portfolio
```

Install the required dependencies:
```bash
npm install
```

### 3. Run the Development Server
Start the Express server:
```bash
npm start
```
The server will start on port `3000`. Open your browser and navigate to:
[http://localhost:3000](http://localhost:3000)
